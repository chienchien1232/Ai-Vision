# Checklist kiểm tra

- [ ] Mở project từ android và build APK.
- [ ] Connect → Connecting → Connected.
- [ ] PING nhận Pong cùng requestId.
- [ ] Phản hồi sai mã bị từ chối.
- [ ] Lệnh quá hạn có lỗi rõ ràng.
- [ ] Disconnect hủy lệnh đang chờ; không hiện kết quả cũ.
- [ ] GET_STATUS hiển thị tên thiết bị và firmware.
- [ ] Disconnect xóa thông tin thiết bị.
- [ ] Retry sau lỗi kết nối hoạt động.
- [ ] Nhận tiếng Việt bằng mic điện thoại khi offline (chưa triển khai).
- [ ] Nạp và kiểm tra boot trên board (chưa có phần cứng).
